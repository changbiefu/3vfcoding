# 国际人成长中心 · 教务管理演示

在线地址：https://changbiefu.github.io/3vfcoding/

纯静态 HTML / CSS / JavaScript，原 PHP 源码仍保留。打开自动使用演示账号 `demo / demo123`，不需要验证码、PHP 服务或数据库。

## 功能

本次按原版 21 个教务控制器补齐菜单及主要演示流程：学生、试听、报名、课程、班级、课时、消课、考勤、异动、积分银行和排行、调课补课停课、课表、教师课时费和排行、结算、费用预警、预警中心、教案、教具及联系簿。

另有成长记录、教师 / 家长 / 学生视角、角色菜单配置，以及会员、附件、配置、语言和日志等框架管理演示，共 37 个导航入口。详细覆盖、规则差异和服务器边界见 [MIGRATION.md](MIGRATION.md)，不将菜单覆盖视为生产功能完全等价。

- 学员、报名、赠课、签到和结算相互关联；修改与撤销会回退原影响，防止重复入账和扣课。
- 新增、编辑、查询、详情、CSV 导出、分页；学员和联系人支持 CSV 模板与批量导入。
- 调课需审核后执行；教师结算支持确认、演示发放与作废。
- 教案、附件保存在本机缓存，单文件最多 600 KB；没有云存储。
- 顶部标签栏支持切换、关闭、关闭其他和返回；按身份记住标签、筛选与页面位置。

## 数据和演示边界

示例均为虚构内容。localStorage 键 `gjr-growth-demo:v1`；本次使用 `extensionVersion: 2` 扩展，保留已有学员余额与记录，无需清空缓存。

数据管理可以导出 / 导入完整 JSON、重置示例和撤销重置。数据仅在当前浏览器来源下保存，换设备不会同步。

教师视角关联李老师，家长 / 学生视角关联林小满。界面按关联数据过滤，但没有真实登录权限或服务器数据隔离。真实支付、消息、服务器黑名单拦截、PHP 插件安装及在线升级不在静态站点执行。

## 修改与验证

以本目录为唯一前端源；不要用早期 `成长中心前端/` 副本覆盖。

```text
node docs/domain.test.mjs
node docs/build.mjs
```

- `domain.js`：业务规则。
- `modules.js`：迁移模块界面和操作。
- `app.js`：基础界面、缓存、角色与标签工作区。
- `style.css`：品牌视觉与响应式布局。
- `index.template.html`、`brand-assets.json`：页面骨架、透明品牌图片。
- `index.html`：构建后独立文件，可直接打开，不依赖外部库或字体。

将修改后的源文件与构建的 `index.html` 一起提交。GitHub Pages 使用 `main` 分支 `/docs`，与原 PHP 运行目录独立。
