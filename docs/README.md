# 国际人成长中心 · 前端演示

纯静态 HTML/CSS/JavaScript，没有服务器 API、PHP 或数据库依赖。

- 入口：`index.html`。所有样式、脚本和品牌图片已内嵌，可直接打开。
- 打开后自动以校区管理员进入。演示账号 `demo`，密码 `demo123`，无需验证码。
- 右上角可切换教师、家长、学生视角。家长与学生默认关联“林小满”。所有身份仅用于演示，不构成账号权限或数据隔离。
- 内置 8 位虚构学员、3 个班级、5 节课程、3 条试听、2 条报名记录、3 条成长记录。日期根据首次打开当天生成。
- 新建与修改保存在当前来源的浏览器 localStorage，键名 `gjr-growth-demo:v1`。刷新保留，设备间不自动同步。
- 演示设置提供备份导出、导入、恢复示例、撤销重置和归档学员恢复。

## 修改页面

1. 修改 `style.css`（外观）、`app.js`（数据与功能）或 `index.template.html`（页面骨架）。
2. 在安装 Node.js 的环境运行 `node docs/build.mjs`，也可从本目录运行 `node build.mjs`。
3. 将更新的源文件和生成的 `index.html` 提交到 GitHub。

`brand-assets.json` 内为原始品牌图提取的透明 PNG；构建后内嵌到 HTML。没有运行时外部依赖，也不会上传用户填入的数据。

## GitHub Pages

仓库 Settings → Pages，使用 Deploy from a branch，选择 `main` 分支下的 `/docs`。此目录独立于原仓库的 PHP 后台。

## 演示范围

学员增改、搜索筛选、归档恢复，班级增改，课程安排及班级/教室/教师时间冲突校验，试听跟进与转学员，报名加课时，课堂签到扣课时和防重复结算，成长记录及角色视角。

这是界面与流程演示，不提供真实登录验证、多设备同步、支付、消息发送或生产环境的权限隔离。品牌图片由机构提供。
