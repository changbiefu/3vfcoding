# 原版功能对照与前端迁移说明

本次依据仓库 `app/backend/controller/edu/`、`app/backend/model/` 和相应表单核对。保留原 PHP 文件，在 `docs/` 中实现适合 GitHub Pages 的业务演示。界面经过品牌重构，**不是原 PHP 系统的逐行转换，也不代表生产功能完全等价**。

## 教务模块

| 原控制器 | 前端菜单 / 路由 | 已实现的演示流程 |
| --- | --- | --- |
| Student | 学员管理 `students` | 学号、基本资料、班级、课时、状态、查询、增改、归档恢复、CSV 模板与批量导入 |
| EduTrialClass | 试听体验课 `trials` | 课程班级、教师、日期时间、来源、跟进状态、详情、增改删除、转学员防重复 |
| EduEnrollment | 续费报名 `enrollments` | 新报、续费、转班、购买和赠送课时、应收实收、支付状态、编辑回退、删除回退 |
| EduCourse | 课程管理 `courses` | 编号、名称、分类、课时、单价、类型、难度、停用、详情与增改删除 |
| EduClass | 班级管理 `classes` | 编号、课程、教师、教室、容量、常规星期时间、总课时、已用统计、查看成员、增改删除 |
| ClassHour | 课时管理 `hours` | 排课、冲突校验、实际课时、全员扣课 / 请假不扣课、签到修订、撤销、删除保护 |
| EduLessonDetail | 消课明细 `deductions` | 从签到生成，记录实际扣课、考勤和当时余量，查询与导出 |
| Attendance | 学生考勤 `attendanceRecords` | 到课、请假、缺勤、补课、迟到、早退；通过课堂入口登记或修订，撤销签到同步撤销记录 |
| StudentChange | 学生异动 `changes` | 请假日期、调班、退费金额和退回课时、赠课、删除赠课、原因、编辑和删除回退 |
| StudentBank | 学生银行 `points` | 积分收入支出、余额、流水、编辑和删除校验，禁止透支 |
| StudentBankRanking | 积分排行榜 `pointRanking` | 按可用积分排序 |
| ScheduleAdjust | 调课补课停课 `adjustments` | 调课、补课、停课、代课、顺延；整班 / 部分学员，审批通过 / 驳回，再执行到课表，补回 / 扣减课时 |
| Timetable | 本周课表 `schedule` | 周切换、日期选择、教师 / 家庭视角过滤、按班级常规时间生成本周课程、导出与打印 |
| TeacherHour | 教师课时费 `teacherHours` | 月份筛选、已签到实际课时汇总、教师单价（教师资料页修改）、费用计算、结算入口 |
| TeacherSettlement | 教师结算 `settlements` | 月度汇总、调整课时、奖励扣减、明细快照、确认 / 演示发放 / 作废，防重复和已确认课时保护 |
| TeacherRanking | 教师排行榜 `teacherRanking` | 班级、学员、常规周课次、请假和退费率；沿用原评分系数 |
| FeeWarning | 费用预警 `feeWarnings` | 五类预警手动维护；扫描课时不足、欠费、合同到期、长期未到课；等级、责任人、跟进备注 |
| WarningCenter | 预警中心 `warnings` | 六类异常维护；扫描排课冲突、班级超员、课时不足；等级、处理状态与备注 |
| TeachingPlan | 教案资料库 `resources` | 分类、关联课程、教师、文本教案、附件、下载次数、增改删除 |
| TeachingAid | 教具申请 `aids` | 数量、申请人、用途、需求日期、审批意见、通过 / 驳回 / 领取 / 归还 |
| CampusContact | 校区联系簿 `contacts` | 姓名、校区、职务、电话、邮箱、备注、CSV 导入导出和增改删除 |

以上是 **21 个原教务控制器** 的菜单和主要业务流程覆盖，不意味着所有原表单字段、导入格式、统计口径与后台行为逐项等价。成长记录、家长和学生视角为本演示新增。

## 框架功能与明确差异

- 教师 / 管理员资料、角色菜单权限、会员 / 分组 / 等级、附件 / 分组、配置 / 分组、语言词条、黑名单记录、操作日志：提供本机维护界面。教师默认使用“授课教师”菜单配置，管理员保留管理入口。
- 真正的登录校验、服务端数据权限、黑名单拦截、PHP 插件安装、在线升级、数据库管理不在静态页面中执行。`系统与迁移说明` 页面说明这些边界；未设置虚假的“安装成功”或“安全生效”。
- 打开自动使用 demo / demo123；身份切换只是演示，所有数据位于同一浏览器。教师固定关联李老师，家长 / 学生关联林小满。
- 原版 Excel 批量导入改为 UTF-8 CSV；可下载模板用 Excel 编辑。服务器附件改为浏览器内嵌文件，单文件上限 600 KB，受 localStorage 总容量限制；不是云文件库。
- 考勤和消课统一由课堂签到联动，避免原版多入口各自登记造成的重复。已签到后转班的学员仍保留原课堂名单；修订先回退旧扣课。
- 报名显式填写购买课时与实收金额，不从报名金额反推课时。已报名 / 已完成才应用购买及赠送课时。历史期初报名只读，避免重复计入已有余额。
- 退费、发放等均为登记，没有实际资金流转。演示中不存在真实短信、支付和多设备同步。
- 删除存在引用的课程 / 班级会阻止；学员采用归档恢复；已执行调整保留审计记录；已确认结算要先作废才可修订关联签到。

## 数据兼容

仍使用 `gjr-growth-demo:v1`。扩展字段 `extensionVersion: 2` 标记本次升级；补充新数组、配置和示例积分，不改动旧学员课时、已有报名、课程及成长数据。不要求用户清空缓存。导出 JSON 包含全部新增模块；旧版本 JSON 可自动补齐字段。

## 代码位置

- `domain.js`：不依赖 DOM 的业务规则，便于将来替换成服务器接口。
- `modules.js`：菜单分组、新模块表单、列表、审批、导入导出与打印。
- `app.js`：原演示界面、角色、标签工作区、缓存与通用组件。
- `build.mjs`：将源文件、样式和品牌图片合成为独立 `index.html`。

不要用早期 `成长中心前端/` 副本覆盖本目录；后续以 `docs/` 为准。
